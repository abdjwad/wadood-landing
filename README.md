# ودود للتجارة — Wadood Trading

صفحة الهبوط الرسمية لتطبيق **ودود للتجارة**: كهربائيات · طاقة بديلة · أدوات صحية.

- ملف واحد مستقل: `index.html` (بدون أي مكتبات أو خطوات بناء).
- عربي RTL، متجاوب مع الموبايل، ويتضمن حاسبة طاقة شمسية تفاعلية.

## تعديل بيانات المتجر

افتح `index.html` وابحث عن `const WADOOD` قرب آخر الملف، وعدّل:

| الحقل | المعنى |
|---|---|
| `phone` | رقم الهاتف كما يظهر في الصفحة |
| `whatsapp` | رقم واتساب بصيغة دولية بدون `+` (مثال `963912345678`) |
| `address` | عنوان المعرض |
| `hours` | أوقات الدوام |
| `playStore` / `appStore` | روابط التطبيق في المتاجر |

## النشر

- **GitHub Pages:** Settings ← Pages ← Source: `main` / root، ثم أضف الدومين في Custom domain.
- **سيرفر Nginx:** انسخ `index.html` إلى مجلد الموقع (مثلاً `/var/www/wadood`).
